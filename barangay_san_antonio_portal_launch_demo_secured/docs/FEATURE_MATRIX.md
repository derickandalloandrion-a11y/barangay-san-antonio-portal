# Consolidated Feature Matrix

| Area | Included in local demo | Requires production work |
|---|---|---|
| Branding / responsive public UI | Existing CSS theme and seal retained; mobile navigation | Approved real photos, media, final content review |
| Articles | Detail pages; three-card expand/collapse | Real editorial content and approval |
| Authentication | Resident / Visitor registration, email verification, password hashing, login lockout | SMTP provider and delivery monitoring |
| RBAC | Resident / Visitor role permissions; Official position permissions; Administrator permissions | Final position / separation-of-duties policy approval |
| Service requests | Document, incident, medicine submission and review | Real operating rules, file attachments, issuance / dispatch processes |
| Appointments | Request, review, confirm / decline, tracking | Live office capacity and scheduling integration |
| FOI | Submit, review, status history | Formal FOI officer, manual, legal response process |
| Feedback | Submit and review | Published response standards and escalation process |
| Privacy | Draft notice and data-subject request form | DPO approval, PIA, retention, breach response |
| Transparency | Publish / list approved document links | Actual official records and downloadable documents |
| Citizen’s Charter | Draft / publish entries | Verified requirements, fees, processing times |
| Content governance | Draft, publish, archive; revision snapshots | Staff ownership and formal approval policy |
| Audit | Key workflow and administrative events | Centralized log management / SIEM |
| Accessibility | Skip link, focus, keyboard dropdowns, text size, contrast, reduced motion | Full WCAG 2.1 AA audit and complete translations |
| PWA / low bandwidth | Static asset cache only; no third-party assets | Full offline workflow design and production HTTPS |
| Payments / national ID / MFA / SMS / QR / API / GIS | Not implemented | Approved providers, agreements, security and integration testing |
| Hosting / WAF / DDoS / monitoring | Local XAMPP only | Approved production hosting and operational controls |
